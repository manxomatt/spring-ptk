# Project Brief: Spring PTK

## Overview
Spring PTK is a Spring Boot REST API application following Domain-Driven Design (DDD) principles with MySQL database integration. It serves as a backend system for PTK (likely a product/inventory management system).

## Core Requirements
- RESTful API endpoints for managing products, brands, and authentication
- JWT-based authentication and authorization
- Domain-Driven Design architecture
- MySQL database persistence
- API documentation via Swagger/OpenAPI

## Project Goals
1. Provide a clean, maintainable codebase following DDD principles
2. Secure API endpoints with JWT authentication
3. Support CRUD operations for various domain entities
4. Offer comprehensive API documentation

## Target Users
- Backend developers integrating with the API
- Frontend applications consuming the REST endpoints
- System administrators managing the application

## Key Features
- Product management (CRUD operations)
- Brand management
- User authentication (login, token refresh)
- Role-based access control
- API documentation with Swagger UI
